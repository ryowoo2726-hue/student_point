#상점 조회 시스템

학생들이 자신의 학번을 입력하여 누적 상점 및 월별 출석 상점 내역을 조회할 수 있는 미니멀 웹 애플리케이션입니다.

## ✨ 주요 기능
- **간편한 학번 조회**: 학번(예: `20201`), 번호(`1번`, `1`), 이름 입력 지원
- **실시간 구글 스프레드시트 연동**: 구글 시트에서 점수 수정 시 웹 화면에 실시간 자동 반영
- **월별 상점 내역**: 각 학생별 탭과 연동되어 월별 출석 상점 및 출석일 세부 내역, 1인 1역 표시
- **미니멀 클린 디자인**: Apple 스타일의 정갈한 반투명 프로스트 글래스모피즘 인터페이스
- **관리자 조회**: 기준 날짜까지의 학생별 총 상점, 공동 순위, 학급 합계와 평균 표시

## 🚀 실행 방법
`app/index.html` 파일을 더블 클릭하여 웹 브라우저(Chrome, Edge 등)로 바로 열 수 있습니다.
로컬 웹 서버 구동 시:
```bash
python -m http.server 5173
```
이후 `http://localhost:5173` 접속.

## 📂 파일 구조
- `app/index.html` : 메인 웹 인터페이스
- `app/style.css` : 클린 매트 글래스 스타일시트
- `app/app.js` : 실시간 구글 시트 동기화 및 인터랙션 로직
- `app/data.js` : 학생 명단 및 시트 탭 매핑 설정
- `app/admin.html` : 날짜별 상점 관리자 화면
- `app/admin.js` : 관리자 화면 및 전체 학생 기록 동기화
- `app/admin-data.js` : 날짜별 출석·역할·추가 상점 계산과 공동 순위

## 관리자 페이지

학생 화면 상단의 **관리자**를 누르거나 `app/admin.html`을 열어 사용합니다.
관리자 비밀번호를 입력하면 현황을 조회할 수 있습니다.
새로고침·재접속 시 비밀번호를 다시 입력해야 하며, 로그아웃 버튼으로 로그인 화면으로 돌아갑니다.
기준 날짜를 변경하면 해당 날짜를 포함한 이전 기록의 상점과 순위가 표시됩니다.
출석은 기록된 출석일마다 1점, 1인 1역은 학생 화면의 상점 기준에 따라 계산합니다.
추가 상점은 학생별 시트 하단의 `날짜`·`상점` 기록으로 합산합니다.
동점은 공동 순위로 처리합니다(예: 1위, 1위, 3위).

관리자 화면은 처음 열 때와 1분마다 구글 시트를 읽습니다. 수동 새로고침도 가능합니다.
조회에 실패하면 저장된 기록을 표시하고 상태 문구로 안내합니다.
날짜가 누락되거나 세부 기록과 합계가 맞지 않는 학생은 확인 가능한 점수를 표시하되,
순위·학급 총 상점·평균에서는 제외합니다.

연도 없는 출석일은 `app/data.js`의 `GOOGLE_SHEET_CONFIG.academicYear`를 기준으로 해석합니다.
1·2월은 다음 해로 계산합니다. 학년도가 바뀌면 이 값을 갱신해주세요.
현재 관리자 페이지는 읽기 전용이며 브라우저에서 비밀번호를 확인하는 간단한 화면 잠금입니다.
서버 인증이 아니므로 소스 확인이나 직접 시트 접근까지 차단하지는 않습니다.

## 계산 검증

Node.js가 설치되어 있으면 다음 명령으로 날짜 경계, 공동 순위, 역할 상점 기준을 검증합니다.

```bash
node --test tests/admin-data.test.cjs
```

실제 구글 시트 30명의 상세 기록과 메인 총 상점을 비교하는 검증도 가능합니다(PowerShell).

```powershell
$env:CHECK_LIVE_SHEETS='1'
node --test tests/admin-data.test.cjs
```
