#상점 조회 시스템

학생들이 자신의 학번을 입력하여 누적 상점 및 월별 출석 상점 내역을 조회할 수 있는 미니멀 웹 애플리케이션입니다.

## ✨ 주요 기능
- **간편한 학번 조회**: 학번(예: `20201`), 번호(`1번`, `1`), 이름 입력 지원
- **실시간 구글 스프레드시트 연동**: 구글 시트에서 점수 수정 시 웹 화면에 실시간 자동 반영
- **월별 상점 내역**: 각 학생별 탭과 연동되어 월별 출석 상점 및 출석일 세부 내역, 1인 1역 표시
- **미니멀 클린 디자인**: Apple 스타일의 정갈한 반투명 프로스트 글래스모피즘 인터페이스

## 🚀 실행 방법
`app/index.html` 파일을 더블 클릭하여 웹 브라우저(Chrome, Edge 등)로 바로 열 수 있습니다.
로컬 웹 서버 구동 시:
```bash
python -m http.server 5173
```
이후 `http://localhost:5173` 접속.

## 📂 파일 구조
- `app/index.html` : 메인 웹 인터페이스
- `app/style.css` : 클린 매트 글래스 스타일시트
- `app/app.js` : 실시간 구글 시트 동기화 및 인터랙션 로직
- `app/data.js` : 학생 명단 및 시트 탭 매핑 설정
